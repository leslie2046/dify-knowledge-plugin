# Privacy Policy

This plugin sends retrieval queries, metadata filters, resource identifiers, and optional retrieval parameters to the Dify Knowledge API endpoint configured in the plugin credentials. When document creation or update tools are invoked, document names, text, and processing settings are also sent to that endpoint and stored by the configured Dify service.

The plugin does not maintain its own database of documents, queries, results, or credentials. Retrieval request parameters may appear in Dify runtime logs. Network traffic is sent only to the configured Dify API base URL.

You are responsible for providing a valid Dify Service API key and for ensuring that the configured endpoint complies with your organization's privacy and data handling requirements.
